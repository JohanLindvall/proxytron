# Code of conduct

Proxytron welcomes people of every background, identity and experience level.
Everyone participating in project issues, pull requests and other project spaces
is expected to help keep them respectful and accessible.

## Working together

- Be patient with questions and explain technical decisions.
- Critique ideas and code respectfully; listen when someone identifies a problem.
- Respect different experiences and communication styles.
- Accept corrections and take responsibility for mistakes.

Harassment, threats, discriminatory remarks, sexual harassment, personal attacks
and publishing another person's private information without permission are not
acceptable.

## Reporting and enforcement

Report concerns privately to maintainer Johan Lindvall at
[johan.lindvall@gmail.com](mailto:johan.lindvall@gmail.com). Include relevant links
and context when you can. Reports will be handled with discretion, with
information shared only as needed to investigate and respond.

Maintainers may remove harmful content, request a correction, warn a participant
or restrict participation temporarily or permanently, depending on severity and
repetition. They should explain moderation decisions to the people involved when
doing so is safe. Concerns about a decision can be sent to the same contact.

This code also applies when someone represents Proxytron publicly.
